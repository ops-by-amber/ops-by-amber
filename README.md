## Featured build — Chat Cleaner Free Beta

**Select multiple ChatGPT conversations using checkboxes, then archive or delete your selection in a batch.**

Chat Cleaner is a free Chrome extension for conversations currently loaded in the ChatGPT sidebar. It uses ChatGPT's own controls, asks for confirmation before deletion, and stops if it cannot safely identify a menu.

**[Download the free beta](https://github.com/ops-by-amber/chat-cleaner-free-beta)** · [Install instructions](https://github.com/ops-by-amber/chat-cleaner-free-beta/blob/main/INSTALL.md) · [Report an issue](https://github.com/ops-by-amber/chat-cleaner-free-beta/issues/new)
