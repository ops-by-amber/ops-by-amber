## Featured project: Chat Cleaner — Free Beta

**Select multiple ChatGPT conversations using checkboxes, then archive or delete your selection in a batch.**

Chat Cleaner is a free Chrome extension that works with conversations currently loaded in the ChatGPT sidebar. It uses ChatGPT's existing controls, asks for confirmation before deletion and stops if it cannot safely identify a menu.

**[Download Chat Cleaner Free Beta](https://github.com/ops-by-amber/chat-cleaner-free-beta)** · [Installation guide](https://github.com/ops-by-amber/chat-cleaner-free-beta/blob/main/INSTALL.md) · [Report a bug / suggest a feature](https://github.com/ops-by-amber/chat-cleaner-free-beta/issues/new)

> **Beta:** Manual Chrome installation requires Developer Mode. Try it on a disposable chat first; deletion cannot be undone. This project is independent and is not affiliated with OpenAI.
